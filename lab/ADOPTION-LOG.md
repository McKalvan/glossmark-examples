# Adoption log

Every showcase example was written with no GlossMark files and then adopted the way a new user would: `gloss init --dry-run`, `gloss init`, the adopt-glossmark skill's steps, `gloss suggest`, `gloss doctor`, `gloss check` and `gloss drift`, all with the v0.1.0 release binary. This log records every friction point on the way, in the order it was hit.

Each entry says what happened, how bad it is, and where it went. **Kind** is one of *bug* (v0.1.0 does something its docs say it should not), *gap* (a design or feature gap), *doc* (the docs are wrong or silent), *ux* (it works, but it misleads or costs time). Entries that became a lab finding link to it.
